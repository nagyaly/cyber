Alert: All links will start the download once you click

## MACOX (Apple Silicon M1/M2..)
1- install UTM [Download](https://github.com/utmapp/UTM/releases/latest/download/UTM.dmg)

2- install Kali Linux (AMD64) 
- Download ISO file [Download](https://cdimage.kali.org/kali-2024.3/kali-linux-2024.3-installer-arm64.iso)
- Add the ISO file to the removable IDE
- Configure the network to bridged (select en0 interface)
- Boot and install Kali linux

3- install Windows 7
- Download configuration file [Download](https://github.com/utmapp/vm-downloads/releases/download/windows-template/windows-7-x64-utm.zip)
- Download ISO file [Download](https://archive.org/download/en_windows_7_ultimate_with_sp1_x64_dvd_u_677332_202006/en_windows_7_ultimate_with_sp1_x64_dvd_u_677332.iso)
- Add the ISO file to the removable IDE
- Configure the network to bridged (select en0 interface)
- Boot and install Windows 7
